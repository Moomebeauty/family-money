系統概述

🎯 核心目標

  • 協助家庭每月追蹤收入與各類支出，達成存錢買房的目標
  • 主要目標：每月存「練習房貸金額 NT$15,606」到股票，同時累積頭期款
  • 固定大支出：房貸 15,606 ／ 藏龍貸款 10,000 ／ 車貸 12,000 ／ 房租 12,500
  • 使用者：伯涵（學校薪資 + 助教收入）、珞熙

📐 技術需求

項目規格
前端框架React 或 Vue 3（任選），支援 PWA 離線使用
資料儲存localStorage 或 IndexedDB（單機），或後端 API（可選）
匯出功能可匯出 Excel（.xlsx）或 CSV
語言繁體中文介面
裝置支援桌面優先，手機版次要（記帳用）
色系奶茶系：主色 #5C4033，強調 #C8956C，底色 #FAF3EB

帳本流水帳規格（共用元件）

📊 頂部儀表板（4 格卡片）

每頁必有
卡片名稱計算方式備註
每月預算固定值（設定時填入）不可修改
本月存入當月所有「正數」金額加總依選取月份篩選
本月支出當月所有「負數」金額加總（取絕對值顯示）依選取月份篩選
累計餘額全部記錄的金額加總（正負相消）黃底標示，用於對帳

📝 流水帳欄位定義

日期
date
格式 YYYY/MM/DD，必填
金額
number
正數 = 存入／負數 = 支出，必填。顯示時正數綠色、負數紅色
類別
select
下拉選單（各帳本不同，見下方定義），必填
說明
text
自由文字，選填
累計餘額
auto
系統自動計算，不可手動輸入。等於該筆及之前所有金額加總
⚠️ 累計餘額欄由系統即時計算，不存進資料庫，每次載入依日期排序重新計算。

🏷️ 各帳本類別選項

帳本每月預算類別選項
🚗 交通費10,000存入、加油停車、汽車保養、過路費、其他
💡 水電通訊5,000存入、電費、水費、瓦斯、網路、手機、其他
🏢 工會保險7,000存入、工會費、勞保健保、地價稅、房屋稅、其他
🧧 紅包基金4,350存入、婚禮、喜宴、過年紅包、生日、其他
💰 基金分配—存入買房頭期款、存入練習房貸、存入股票、存入預備金、存入旅遊、存入進修、存入紅包、提領

📊 右側統計區

  • 顯示各類別的累計金額（SUMIF 等效），排除「存入」類別
  • 顯示當前篩選月份的小計（本月支出合計）
  • 月份小計可一鍵複製，用於填入「12月份紀錄」

季報 & 年報

📈 季報計算（資料來源：12月份紀錄）

季別涵蓋月份
Q18月、9月、10月
Q211月、12月、1月
Q32月、3月、4月
Q45月、6月、7月
  • 季總收入 = 三個月月總收入加總
  • 季總支出 = 三個月月總支出加總
  • 季淨結餘 = 季總收入 − 季總支出
  • 練習房貸達成率 = 三個月存入股票加總 ÷ (15,606 × 3)

🏆 年報計算

  • 年度總收入 = 12 個月月總收入加總
  • 各類固定支出年度合計（房貸、車貸、房租、藏龍）
  • 各類浮動支出年度合計（交通、水電、工會、紅包）
  • 各支出佔年收入比例（%）
  • 6 大目標達成率：頭期款、練習房貸、股票、預備金、旅遊、進修
  • 年度淨結餘 = 年總收入 − 年總支出
  • 年度反思文字區（自由輸入，可儲存）

核心計算規則

🔢 關鍵公式

// 累計餘額（流水帳）
第 N 筆累計餘額 = SUM(第1筆金額 ... 第N筆金額)

// 本月存入（頂部卡片）
本月存入 = SUMIF(當月紀錄, 金額 > 0)

// 本月支出（頂部卡片）
本月支出 = ABS(SUMIF(當月紀錄, 金額 < 0))

// 對帳差額
差額 = 帳戶實際餘額 − 帳本累計餘額

// 月淨結餘
月淨結餘 = 月總收入 − 月總支出

// 練習房貸達成率
達成率 = 本月存入股票 ÷ 15,606 × 100%
